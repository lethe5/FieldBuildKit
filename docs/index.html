완성 결과

QField에서 바로 여는 .qgs·GeoPackage와 필요 시 MBTiles, 선택한 분류·확률 데이터가 한 폴더에 생성됩니다.

선택한 자료는 프로젝트 내부 형식으로 변환되므로 원본 엑셀·TIFF 경로에 의존하지 않습니다.
STEP 01 · PROJECT BASICS

프로젝트 이름과 저장 위치를 정합니다

08 / 20
01

이름·폴더·좌표계 입력

기존 상위 폴더를 고르면 그 안에 새 프로젝트 폴더가 자동으로 만들어집니다.

  • 프로젝트 이름과 설명 입력
  • 저장할 상위 폴더 선택
  • 작업 CRS와 저장 CRS 확인
처음이라면 기본값 EPSG:5186 / EPSG:4326을 유지해도 됩니다.

05

필요한 자료만 직접 연결

앱에 분류·분포 자료를 내장하지 않고, 사용자가 가진 로컬 파일을 선택적으로 지정합니다.

  • 식물 분류 Excel(.xlsx) 업로드 → 자동 검증·미리보기
  • 사진 식별과 유효한 Excel 사용 시 TIFF 폴더 선택 가능
  • Excel·TIFF 없이도 프로젝트 생성 가능
Excel을 사용하면 국가생물종목록 정명과 KTSN을 적용하고, TIFF를 사용하면 위치별 출현확률을 함께 제시합니다.

STEP 04 · BASEMAP

현장의 인터넷 환경을 선택합니다

11 / 20
04

온라인·오프라인·없음

조사 지역의 통신 상태와 필요한 지도 수준에 맞춰 선택합니다.

  • 온라인: 현장 네트워크 사용
  • 오프라인: 로컬 배경지도 생성
  • 없음: 가장 가벼운 프로젝트
산지나 음영 지역은 출발 전에 오프라인 지도를 준비하세요.
STEP 06 · SYMBOL STYLE

06

기본 스타일 또는
Tabler 아이콘

이번 프로젝트의 모든 포인트와 폴리곤 레이어에 한 번에 적용됩니다.

  • 빠르게 시작: 기본 미니멀 스타일
  • 대상 구분 강화: Tabler 아이콘 검색
예시는 ‘leaf’를 선택한 화면입니다. 아이콘을 선택하지 않으면 기본 미니멀 기호가 적용됩니다.
